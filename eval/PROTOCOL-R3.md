# R3 物理隔离重跑协议（运行前冻结）

> 冻结时间：2026-10-29。任何运行后不得修改样本、臂、判定口径或污染处理规则。R2 的 ≥15% 相对提升线在 baseline 96.43% 时不可达，属于设计错误；本协议不再使用该线。

## 1. 样本与臂

核心干净样本：

- pr-008：`bpierre/dnum` 真实负数进位/丢符号 bug/fix 对。
- pr-009：`bpierre/dnum compare()` 数组字典序比较 bug/fix 对。

可选样本：pr-007，仅在前六个臂完成且剩余预算 ≥$0.15 时加入。

每臂每 PR 仅 1 次：

1. 无插件 baseline 单审。
2. jury `single`。
3. jury `standard`（截断修复后）。

同模型 `deepseek-account/deepseek-flash`、reasoning high、同 diff。可选 A/A 仅为 pr-008 baseline 再跑 1 次，且必须最后执行。

## 2. 物理隔离与污染判定

- 工作区固定为 `eval/r3-isolated/pr-00X/`，每个目录只包含目标 diff 文件。GT、fix.patch、协议、历史日志、报告和源码不得出现在工作区。
- 评审 prompt 明确：只读指定 diff，不得读取任何其他文件、补丁、GT、协议或历史日志，不得联网查找修复提交。
- 每次运行后检查事件流全部工具调用。若出现读取 GT/fix/协议/历史日志/其他文件，或联网检索修复提交，该次立即标为污染并作废，不计入召回或成本收益结论；成本仍记账。
- 评审结束后才可把 GT 用于人工盲裁。

## 3. 成本与运行上限

- 全部 R3 dsh 成本 ≤ **$0.60**，按谷时价：input $0.15/M、cacheRead $0.003/M、output $0.60/M。
- 核心样本最多 6 次，pr-007 可选增加最多 3 次，A/A 可选增加 1 次，总次数 ≤10。
- 每次结束立即从真实父子会话 usage 计算当次和累计成本，写入 `eval/budget-R3.md`；接近上限立即停止，剩余项标为未运行。

## 4. 盲裁与报告指标

- 召回：对照 GT 语义命中，行号不要求一致。
- 误报：finding 缺乏代码事实或被代码反驳；uncertain 单列，不自动算误报。
- 证据率：带 file:line 的 finding 比例。
- 成本：分别列非缓存输入、缓存读、输出和美元；增量边际成本只在严格增量 >0 时计算。
- 当前无独立 explore 子代理可用时使用协调者人工盲裁，必须明确披露，不得冒充独立评审。

## 5. 可达产品规则（运行前写死）

- 若 standard 在 **≥2/3 干净样本** 上严格多于 baseline，则恢复“高危建议 standard”的推荐。
- 否则维持 single 默认，standard 仅作显式选项。
- 若核心样本只有 2 个，则必须 2/2 严格多于才能恢复；若 pr-007 加入，则按 2/3 执行。
- 被污染的运行不得计入分母；因污染导致样本不足时，只报告“无法判定”，不得用其他历史数据补足。

## 6. 预设结论

- 未达到恢复线：single 保持默认；standard 不主张默认召回优势。
- standard 截断或大量误报：先修可靠性/合成，不讨论召回增量。
- 增量边际成本 >$0.15/雷：即使恢复 standard，也不得宣称普遍成本优势。
- gate+intent 只作独立价值，不得代替干净 A/B 召回证据。
